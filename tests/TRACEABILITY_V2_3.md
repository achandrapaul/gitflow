## Coverage and evidence workflow
1. For each approved feature, keep stable IDs and link the relevant test fixture IDs.
2. On actual implementation, fill in repo source module, fixture, test run/commit/OS and result: Not implemented, Implemented-unverified, Passed, Failed or Blocked.

4. If an exact test contradicts the normative specification, the normative specification prevails; correct the test and record the change.
5. Do not derive approval for a new feature from a test alone.
